# Plans

Use this directory for proposals and implementation plans that have enough
shape to guide discussion or future work.

A practical outline is:

```markdown
# Plan title

## Goal

## Context

## Proposed approach

## Scope and non-goals

## Risks and decisions

## Next steps
```

Keep plans focused and link back to related material in `ideas/` when the plan
grew out of an earlier concept.
