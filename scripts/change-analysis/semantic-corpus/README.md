# Fixed correspondence corpus

Thirty JS/TS comparisons authored/selected on 2026-10-22, before candidate-engine
execution. `manifest.json` is generated by `../make-semantic-corpus.js` from
explicit synthetic source and pinned public Bygone history. Its SHA-256 is
`845dfeaf2cfe6bcc59ab6df23b404afcdb915c175cde74241488c0f299fd42f0`.

The ten controls exercise exact/edited moves, retained/repeated content,
line-number shifts, unrelated replacement, whole-file relocation, arrows,
and invalid syntax. Ten mixed cases exercise extraction/inline, classes,
move/rename/edit, lexical/import binding changes, Unicode literals, anonymous
defaults, registrations, and an unchanged origin outside search scope. These
are small authored policy examples, not independent natural-history ground truth.

The ten historical cases select the first alphabetically sorted changed `src/`
JS/TS path with <=180 lines per non-merge commit, descending from pinned
`9d56b11`, within its last 60 non-merge commits. This selection is independent
of detector success, but deliberately restricted to small files. The `.d.ts`
case is retained as a declaration-only exclusion check. These single-file cases
check inventories/continuations and false cross-file links; they contain no
labeled positive cross-file pair and cannot establish historical move recall.

Ten cases (mixed 06–10 and history 06–10) were marked held out before execution.
There was no detector tuning. This tests a fixed integration, not generalization
from a learned model. Historical function names and continuations were checked
against pinned definitions/diffs before engine execution. Type declarations,
interfaces, and body-less overloads are not in that function denominator.

Fourteen synthetic operation relationships have explicit source/destination
labels. Ten comparisons also have full top-level function inventory annotations.
“Expected” is the authored relationship, not a claim of semantic equivalence.
The extraction/inline fixtures include a cross-file helper reference without
adding an import; that scope repair remains outside the selected relationship.
This is a limitation when interpreting the extraction miss, not evidence that
RefactoringMiner cannot detect well-formed cross-file extraction. Do not revise
these frozen inputs after seeing results; use a separate diagnostic case.

`mixed-10` retains the complete pair as evidence but excludes byte-identical
files before supplying inputs, explicitly testing changed-files-only scope.
The other cases supply every listed file. Raw inputs and expected labels stay
together, and the run records the actual input paths. No private fixtures or
external source dependencies were copied into the manifest.
