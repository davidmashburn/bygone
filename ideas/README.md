# Ideas

Use this directory for early-stage concepts, open questions, rough proposals,
and possibilities that are useful to keep but are not yet ready for execution.

An idea document should make the thinking easy to resume. A practical outline
is:

```markdown
# Idea title

## Summary

## Why it might matter

## Open questions

## Possible next steps
```

Move or adapt an idea into `plans/` once its goal, scope, and next steps are
clear enough to discuss as an actionable plan.
