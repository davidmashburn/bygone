## 0.7.0

- Added merge-base branch review with rename pairing, binary and image comparison, and consistent navigation across Git workflows
- Improved semantic highlighting, line-click selection, connector rendering, and multi-panel interaction consistency
- Added generated shell completions, desktop CLI installation, local rebuild/install automation, linting, and renderer bundle budgets
- Added authored, code-connected change tours, bounded LLM context, the PR Tour Guide skill, hot reload, and independent narrative and file navigation

- Added a [guided 0.6 development tour](./tours/v0.6.bygone.yaml) covering the complete range from `v0.5.2`
