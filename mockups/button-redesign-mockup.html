Interpretation guide

This page shows the shell as a labeled system rather than a polished app screen. The intent is to make the button groups and their scope obvious.

File / directory axis Context bar and navigator rail shift between file drill-down and directory browsing.
Git / non-git axis Timeline only appears in git-backed views and handles commit stepping.
Copy and save Mutation actions stay in the footer so they do not compete with traversal.
Context
Back to directory, breadcrumb trail, current file or directory label
Timeline
Previous / next commit, commit position, left and right commit labels
Rail
Directory tree, changed files, or history list depending on mode
Canvas
Previous / next change and previous / next file within the current compare
Action bar
Copy left / right, save, open external, palette, help
Standalone file diffRail hidden, no directory context
File drill-down diffBack visible, rail is changed files
Directory diffRail is tree
File historyTimeline visible, rail is history list
Directory historyTimeline visible, rail can switch tree / changed files
