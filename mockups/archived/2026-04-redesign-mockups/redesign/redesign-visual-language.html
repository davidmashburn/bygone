Bygone — UI tweaks proposal

Scoped to button-placement and chrome tightening. Not a visual redesign. Every color, pane layout, and visual diff signal below matches what the app already ships. Compare against current-state.html.

  • Palette preserved: green = one-sided change, blue = paired/modified.
  • Flowing canvas connectors between panes (and between directory-diff columns) are preserved — shown here as SVG bezier polygons since this is a static mockup.
  • Header goes from a 4-row stack (app header + context bar + history toolbar + change toolbar) to a single 40px row with the mode-specific actions grouped on the right.
  • The "change-hint" text (F7 / Shift+F7 …) moves into a thin status bar at the bottom instead of floating below the toolbar.
  • Same three screens as current-state.html: two-way file diff, directory diff, file history. No merge tool, no drop state, no timeline rail.
1. Two-way file diff. Four toolbar rows collapse into one. Change navigation (Prev/Next/Prev File/Next File) groups into a single segmented control. Editing toggle sits next to it. F7/Shift+F7 hint moves to the status bar. Breadcrumb and scope share the middle cell.
